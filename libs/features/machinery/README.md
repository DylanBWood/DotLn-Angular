# Machinery

The placeholder at `/machinery` for the machinery view: a page on the house empty-state
template that links back to the board.

A lazy sub-app: `@dotln-angular/machinery` exports only `machineryRoutes`, and test kits come
from `@dotln-angular/machinery/testing`.

Read [the sub-app convention](../../../docs/dev-reference/architecture/sub-apps.md).

Run `npx nx test machinery` and `npx nx lint machinery`.
