# Scene

The app's root, at `/scene`: twenty units on a dark field, a rail of the tools the engine
runs, real-time-strategy selection, instruments, trials and saved compositions.

A lazy sub-app: `@dotln-angular/scene` exports only `sceneRoutes`, and test kits come from
`@dotln-angular/scene/testing`.

Read [the scene architecture](../../../docs/dev-reference/architecture/scene.md) and
[the scene rules](../../../docs/ai-reference/scene-rules.md).

Run `npx nx test scene` and `npx nx lint scene`.
