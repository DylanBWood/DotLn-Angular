# Core

What the app needs at boot: the typed environment and its token, the base path, the route
enums and `buildRoute()`, and the provider functions `provideDotlnCore()` and
`provideDotlnI18n()`.

Import from `@dotln-angular/core`; test kits come from `@dotln-angular/core/testing`.

Read [the foundation libraries](../../../docs/dev-reference/architecture/foundation.md).

Run `npx nx test core` and `npx nx lint core`.
