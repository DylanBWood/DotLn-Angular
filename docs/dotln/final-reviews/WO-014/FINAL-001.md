## Implementation review

The change applies the Design as written, and the convention is legible from the directories. The check layers what the schema cannot say: unique ids, the id equal to the map's slug and line, complete line coverage per map, digest agreement, parameter ranges, and the summary's counts and examples recomputed from the data; its diagnostics print a batch, a pointer whose unknown segments become `[field]`, and a failure category, never a value or a path. The merge validates every incoming checkpoint before it replaces any file and writes through a temporary name. The loader is the seam the order asked for: `CatalogToken` over a one-method interface, bundled chunks behind `provideCatalog()`, a pending promise shared per work and evicted on failure, and the test kit substituting an in-memory loader through the same provider; the facade and the store know nothing of import paths. The facade derives the fifty-row page, bounds the page to the filtered length and selects only a visible row; `revealSelected` returns to the selected row's page.
