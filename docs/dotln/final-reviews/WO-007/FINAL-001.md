## Implementation review

The change applies the Design as written and the tier rule is legible from the directories: one file per group under its tier, sources that carry the tier in their name, a spec that binds the two, and a hygiene check that reads every consumer and refuses a same-tier mapping except an action's own outcomes. `withCommand` is the one place a trinity is wired, and it keeps the three concerns apart: the reducer sets call state from the three events, the handler maps the trigger through a deferred call in the injector, and the outcome is an event, never a method. The interceptors read in order: the base-URL interceptor resolves a relative path against `apiBaseUrl` on `document.baseURI` and lets an absolute or protocol-relative URL through, the error interceptor maps `HttpErrorResponse` and `TimeoutError` to a typed `AppError` with the request's correlation id and dispatches `errorEvents.httpFailed` before rethrowing, and the timeout interceptor sits after it so its error is the one mapped; the timeout spec proves the correlation id survives. The i18n loader now builds absolute URLs so the base-URL interceptor cannot prefix the translation files, and `events-and-state.md` says why.

The board's data path reads in one line from container to HTTP: `BoardPage` renders `vm`, the facade dispatches `boardPageEvents` and composes `BoardStore` with the feature flags, the store maps the page events to `load`, `BoardApi` requests the relative `uifa-board-v1` path, and MSW answers it in development and tests. The facade's fragment handling is the subtle part: it reads the router's fragment as a signal, focuses the target once the document arrives, clears a fragment that an explicit panel selection supersedes by navigating with the query preserved, and reveals the provenance footer while an evidence or source fragment is active; the link mapper builds `/board?…#target` from the current query so a copied anchor opens the board with its panel selected and the target focused, and it lets a modified click open a new tab. The production elimination of the mock path through the builder define, with the asset ignore for the worker, is the right call over a runtime branch alone; D005 measured the chunk a runtime branch leaves behind. The error handler extends Angular's and delegates first, so the console keeps the original error and stack, and the notice store keeps the event's source so the shell names a request failure only for an HTTP failure. The persisted-state feature writes one namespaced key with the selected slice only, validates what it restores and degrades to the in-memory default on a throwing storage, bad JSON or an unknown panel id, each with a spec. The data-access boundary is now a layer tag beside the type tag, so a feature's data-access may import the shared helpers and still not a peer, with a lint fixture for each direction.
