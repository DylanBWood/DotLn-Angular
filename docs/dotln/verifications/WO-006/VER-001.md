- **F1 — follow-up, accessibility defect, medium.**
  [WO-006-D013](../../evidence/WO-006/decisions.md#wo-006-d013),
  `FUP-bad9c9ecbecaca67`. The shell's skip link (`href="#main-content"`) and
  the board's local anchors resolve against `<base href="/">`. Reproduction:
  on the production build, select Work, focus the skip link and press Enter.
  Observed: a second document request, the URL `/board#main-content`, `main`
  focused, and Actors selected again. Expected: focus moves to `main` without
  a navigation. Board anchors such as `#evidence-1` resolve to `/#evidence-1`
  for new-tab and copied links; primary clicks are intercepted and work.
  Rule a repair must hold: the skip link moves focus without a document
  navigation and keeps the layout free of injection (R1). The keyboard e2e
  starts from a non-initial panel and asserts one document load and the
  preserved selection.
- **F2 — follow-up, evidence and performance, medium; reopens WO-006-D002.**
  [WO-006-D014](../../evidence/WO-006/decisions.md#wo-006-d014),
  `FUP-7bbf34bdd0925297`. Metafile attribution at this tree: the lazy board
  chunk (208,017 B) is 190,361 B of fixture and 17,075 B of house code, with
  no Aria or CDK. Aria (14,431 B) and CDK (50,881 B, of which the overlay
  module is 36,745 B) sit in a 276,796 B shared chunk (85,363 B gzip) that
  `main` imports statically, so they are part of the initial load. The app
  shows no menu but registers `provideDotlnUi()`, which imports
  `OverlayModule`; whether that call alone pins the overlay was not isolated.
  Rule a repair must hold: the console-framework evidence names each
  package's bytes and whether they are initial or lazy, and any provider
  change is measured before and after.
- **F3 — follow-up, lint coverage, low.**
  [WO-006-D015](../../evidence/WO-006/decisions.md#wo-006-d015),
  `FUP-78ae6c5fa43ff2b7`. In a fragment, `import { inject as use }` followed
  by `use(ElementRef)` reports nothing, and so does `core.inject(...)` through
  a namespace import. In a container, `import('@angular/cdk/a11y')` reports
  nothing, while the static import is refused. The aliased call also escapes
  criterion 2's grep. This is the same class as WO-005-D011, kept as a
  separate item. Rule a repair must hold: every binding of `inject` and
  every dynamic behavior import is refused where the static form is, each
  with a failing fixture and a passing control.
- **F4 — follow-up, workspace performance, low.**
  [WO-006-D016](../../evidence/WO-006/decisions.md#wo-006-d016),
  `FUP-2fd99c45dad9286d`. `nx.json` gains `"parallel": 1` for every developer
  and CI run, with no decision recording it. On the uncached run, Nx reported
  33.1 s of 49.8 s (66%) recoverable with parallelism, at a 979 MB peak
  against a 3.22 GB budget. Rule a repair must hold: the bound sits where the
  constraint lives, or a decision records the serial default with its cost.
