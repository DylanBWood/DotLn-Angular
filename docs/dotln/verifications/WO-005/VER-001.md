## Findings

All seven are follow-ups; none breaks a criterion or a behavior `main` had.
Each is recorded in the order's [decisions](../../evidence/WO-005/decisions.md)
with a named follow-up and synced to `docs/planning/followups.json`.

- **F1** (follow-up, medium; WO-005-D008, `FUP-0dab0b63b20fae7d`).
  `@typescript-eslint/prefer-readonly` never applies to app or library files.
  The root block scoped to `apps/**/*.ts` and `libs/**/*.ts` is spread into
  each project's `eslint.config.mjs`, and ESLint resolves those patterns from
  the project's directory. `npx eslint --print-config` on
  `libs/shared/i18n/src/lib/transloco-http-loader.ts` and
  `apps/dotln/src/app/home.ts` shows neither the rule nor `projectService`.
  With `--config eslint.config.mjs` both appear and the current files pass.
  Repair rule: `--print-config` on any `libs/shared` or `apps/dotln` `.ts`
  file lists the rule with type information, and a fixture linted under a
  project configuration fails on a never-reassigned private member.
- **F2** (follow-up, medium; WO-005-D009, `FUP-83a2838dd2a2a199`). The
  production bundle carries 366 of 367 Ramda modules (54,156 bytes) and 235 of
  236 Ramda Adjunct modules (31,770 bytes) for four used functions. Initial
  total: 335.43 kB raw, 90.24 kB estimated transfer. With explicit re-exports
  of the used functions behind the same `import { R, RA }`, a scratch build
  gives 258.57 kB raw and 71.73 kB transfer. House rule 1 ranks browser speed
  above house preference. The Design prescribes the full namespace, so the
  repair goes through the planning route. Repair rule: consumers keep
  `import { R, RA } from '@dotln-angular/utils'`, and the build's stats show
  only the modules the used functions need.
- **F3** (follow-up, low; WO-005-D010, `FUP-b1a9d24ace157463`).
  `check:templates` parses the host page `apps/dotln/src/index.html` as a
  template and refuses `main`'s `<title>DotLn</title>`, so the change ships
  `<title></title>`. The WHATWG HTML standard (§4.2.2, read 2026-10-20) gives
  the title element the content model "Text that is not inter-element
  whitespace", so an empty title is non-conforming. The served document has no
  title until Home sets it, and none for clients that run no script.
  It is a follow-up rather than blocking for three reasons: the after-load
  title that `main`'s e2e asserts still holds, no criterion covers the host
  page, and moving user-facing text into Transloco follows house rule 9.
  Repair rule: the served `index.html` carries a non-empty `<title>`, and the
  template check covers component templates without refusing it.
- **F4** (follow-up, low; WO-005-D011, `FUP-1ce1fb75025a93f8`). Each
  structural check passes a form it does not judge:
  - **Tokens:** a parenthesized, `const`-aliased or locally re-exported
    `InjectionToken` constructor (in both `check:tokens` and the lint rule).
  - **Kits:** tokens declared as class statics or object members, and
    `getTestBed()` receivers.
  - **Templates:** a shorthand `template` property naming a variable (0
    findings), plus `[textContent]`, `[innerHTML]`, button `value` and
    `<option label>` text.

  None of these forms is in the workspace, so criteria 2, 4 and 5 hold; this
  meets D007's reopening condition. Repair rule: each check judges or refuses
  every listed form, with a fixture for each.
- **F5** (follow-up, low; WO-005-D012, `FUP-f1894f519161c905`). The target's
  `docs/dev-reference/README.md`, untouched by the diff, still calls the home
  route eager and describes the old `app.config.ts`, and it links no
  foundation material. The generator log's new headings left
  `Installed generator help` empty, and the six foundation commands appear in
  two formats under unrelated headings. Repair rule: the index describes the
  current app and links the foundation reference; the log keeps its section
  and records each command and result in order, in one format.
- **F6** (follow-up, low; WO-005-D013, `FUP-06298bb21fc18859`). Disabling the
  Angular cache also disables the dev server's Vite dependency prebundling
  (`dev-server/options.js`; the warning above). D003, the profile and the
  generator log name only the lost incremental disk cache. Repair rule: the
  recorded cache finding names the prebundling loss beside the disk cache.
- **F7** (follow-up, planning; WO-005-D014, `FUP-4404b58447422b81`). WS-001's
  house rule 15 still limits core and i18n to util and models, while D001
  admits core → i18n in the target. Repair rule: the next planning pass that
